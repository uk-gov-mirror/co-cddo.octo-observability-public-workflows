Extract the current GitHub Action into a standalone, multi-platform Docker image that can retrieve SBOMs from different source control platforms (GitHub, GitLab, etc.) using their native APIs, authenticate with the ingestion API via either API key or OIDC token exchange, and run in any CI system (GitHub Actions, GitLab CI, Jenkins, etc.) via a simple docker run. Existing GitHub Action users get a backwards-compatible wrapper backed by the new image.
